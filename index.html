# المعرِض لوحة متابعة أداء وإيرادات المحفظة الاستثمارية — صفحة ويب واحدة (HTML/CSS/JS بدون سيرفر خلفي). ## التشغيل محليًا افتح ملف `index.html` مباشرة في أي متصفح. ## النشر عبر GitHub Pages 1. تأكد أن هذا المستودع عام (Public). 2. من إعدادات المستودع Settings → Pages، اختر الفرع `main` والمجلد `/ (root)`، ثم احفظ. 3. بعد دقيقة أو دقيقتين سيصبح متاحًا على رابط من نوع: `https://.github.io/<اسم-المستودع>/` ## تحديث البيانات داخل التطبيق نفسه زر "تحديث البيانات من ملف إكسل" يقرأ أي ملف إكسل بنفس هيكلة شيت "المبيعات" ويحدّث كل الأرقام والرسوم مباشرة في المتصفح، دون الحاجة لأي تعديل على الكود أو رفع ملف جديد لهذا المستودع. ## الربط مع Firebase الموقع مجهّز للاتصال بـ Firebase (Firestore لتخزين آخر نسخة من البيانات + Authentication لحماية عملية التحديث + Hosting للنشر). طالما لم تُستبدل الإعدادات، يعمل الموقع بشكل طبيعي محليًا كما كان (بدون Firebase). ### 1) إنشاء المشروع 1. افتح [console.firebase.google.com](https://console.firebase.google.com) وأنشئ مشروعًا جديدًا. 2. من داخل المشروع: **Build → Firestore Database → Create database** (اختر وضع الإنتاج Production mode). 3. من **Build → Authentication → Sign-in method** فعّل **Email/Password**، ثم من تبويب **Users** أضف مستخدمًا (بريدك وكلمة مرور) — هذا هو الحساب الذي سيسجّل الدخول لحفظ التحديثات. 4. من **Project settings (⚙) → General → Your apps**، أضف تطبيق ويب () وانسخ كائن `firebaseConfig` الذي يظهر لك. ### 2) ربط الكود 1. افتح `index.html`، ابحث عن `const firebaseConfig = {` (قرب بداية السكربت الرئيسي)، واستبدل القيم `REPLACE_WITH_...` بالقيم الحقيقية التي نسختها. 2. افتح `.firebaserc` واستبدل `REPLACE_WITH_YOUR_FIREBASE_PROJECT_ID` بمعرّف مشروعك (Project ID). ### 3) النشر ```bash npm install -g firebase-tools # أول مرة فقط firebase login firebase deploy ``` هذا الأمر ينشر الموقع على Firebase Hosting وينشر أيضًا قواعد الحماية في `firestore.rules` (قراءة عامة، وكتابة فقط للمستخدم المسجّل دخوله). ### كيف يعمل الربط - عند فتح الصفحة، يحاول الموقع أولًا جلب آخر بيانات محفوظة من Firestore (مستند `portfolio/latest`)؛ إن لم توجد، يعرض البيانات المرفقة أصلًا في الملف. - زر "تسجيل الدخول (Firebase)" يظهر تلقائيًا في شريط الأزرار بمجرد تفعيل الإعدادات أعلاه. - بعد تسجيل الدخول، أي رفع لملف إكسل عبر زر "تحديث البيانات من ملف إكسل" يُحفظ تلقائيًا في Firestore، فتظهر البيانات المحدَّثة لكل زوار الموقع من أي جهاز دون الحاجة لإعادة رفع الملف يدويًا لكل زائر.

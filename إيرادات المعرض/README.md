# المعرِض

لوحة متابعة أداء وإيرادات المحفظة الاستثمارية — صفحة ويب واحدة (HTML/CSS/JS بدون سيرفر خلفي).

## التشغيل محليًا
افتح ملف `index.html` مباشرة في أي متصفح.

## النشر عبر GitHub Pages
1. تأكد أن هذا المستودع عام (Public).
2. من إعدادات المستودع Settings → Pages، اختر الفرع `main` والمجلد `/ (root)`، ثم احفظ.
3. بعد دقيقة أو دقيقتين سيصبح متاحًا على رابط من نوع:
   `https://<username>.github.io/<اسم-المستودع>/`

## تحديث البيانات
داخل التطبيق نفسه زر "تحديث البيانات من ملف إكسل" يقرأ أي ملف إكسل بنفس هيكلة شيت "المبيعات" ويحدّث كل الأرقام والرسوم مباشرة في المتصفح، دون الحاجة لأي تعديل على الكود أو رفع ملف جديد لهذا المستودع.
